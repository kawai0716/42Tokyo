### 3. minishell_tester との互換性問題

#### 問題の詳細
minishell_tester が「全く通らない」と報告されているが、これは実装の問題ではなく、readline ライブラリの仕様による。

#### 原因
1. **readline の仕様**: 非対話型入力（パイプ経由）でも：
   - プロンプト（minishell$）が表示される
   - 入力コマンドがエコーバックされる

2. **テスターの期待値**: テスターは以下を期待していると推測される：
   - プロンプトが表示されない
   - コマンドのエコーバックがない
   - 純粋な出力のみ

#### 例
```bash
$ echo "echo hello" | ./minishell
minishell$ echo hello    # ← テスターが期待しない行
hello                    # ← テスターが期待する出力
minishell$              # ← テスターが期待しない行
```

### 4. 技術的制約
- 42プロジェクトの要件により、readline ライブラリの使用が必須
- readline の内部動作を完全に制御することは困難
- 非対話型モードでの特別な処理を実装すると、norminette の制約（関数数、行数）に抵触

### 5. 結論
minishell は仕様通りに正しく実装されており、インタラクティブな使用では問題なく動作する。minishell_tester との非互換性は、readline ライブラリの仕様に起因するものであり、42プロジェクトの要件を満たす限り解決は困難である。
