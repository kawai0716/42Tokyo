## 失敗テスト分類と修正計画

### カテゴリ1: 複数リダイレクション処理問題 (18テスト)
**問題**: 同一コマンドで複数の出力リダイレクションが正しく処理されない

**失敗テスト**:
- Test 84, 85, 88: 複数出力リダイレクション (`ls >file1 >file2`)
- Test 92, 93, 94: パイプ＋複数リダイレクション
- Test 113, 114, 116-119: append複数リダイレクション (`>>`)
- Test 122-124, 127, 129: パイプ＋append複数リダイレクション

**現在の問題**: 
- リダイレクション処理で最後のファイルのみが処理される
- 複数ファイルへの同時出力ができない

**修正方針**:
1. **リダイレクション処理の改修**: `redirect.c`で複数出力を処理
2. **ファイルディスクリプタ管理**: 複数ファイルへの`tee`的な機能実装
3. **エラーハンドリング**: 一部ファイルが失敗した場合の適切な処理

**実装優先度**: ⭐⭐⭐ (高)

### カテゴリ2: 混在引数・リダイレクション処理問題 (8テスト)
**問題**: 引数とリダイレクションが混在する場合の解析エラー

**失敗テスト**:
- Test 59: `echo hi < ./test_files/infile bye bye`
- Test 61: `echo <"./test_files/infile" "bonjour       42"`
- Test 63: `cat <./test_files/infile_big ./test_files/infile`
- Test 83: `echo hi >         ./outfiles/outfile01 bye`
- Test 100: `echo hi | >./outfiles/outfile01 echo bye >./test_files/invalid_permission`

**現在の問題**:
- パーサーが引数とリダイレクションの任意順序を正しく処理できない
- bashでは`cmd arg1 < input arg2 > output arg3`が有効だが、minishellで失敗

**修正方針**:
1. **パーサー改修**: `parse_command.c`で混在解析の実装
2. **トークン順序処理**: 引数とリダイレクションを分離収集
3. **実行時再構築**: 正しい実行形式への変換

**実装優先度**: ⭐⭐⭐ (高)

### カテゴリ3: パイプライン複雑処理問題 (2テスト)
**問題**: 複雑なパイプチェーンでの処理不正確

**失敗テスト**:
- Test 53: `env | sort | grep -v SHLVL | grep -v ^_`
- Test 80: `echo <123 <456 hi | echo 42`

**現在の問題**:
- 長いパイプチェーンでの環境変数処理
- パイプ内でのリダイレクション処理

**修正方針**:
1. **パイプライン改善**: `pipe.c`での複数段パイプ処理強化
2. **環境変数の一貫性**: パイプ間での環境変数継承改善

**実装優先度**: ⭐⭐ (中)

### カテゴリ4: エラーハンドリング・エッジケース (4テスト)
**問題**: 特殊なエラーケースや構文の処理

**失敗テスト**:
- Test 60: `grep hi <./test_files/infile_big <./test_files/infile`
- Test 104, 105, 108: 不正ファイル＋リダイレクション組み合わせ
- Test 130: `cat <minishell.h>./outfiles/outfile`

**修正方針**:
1. **エラー処理統一**: 一貫したエラーメッセージとコード
2. **構文解析強化**: 特殊ケースの適切な処理

**実装優先度**: ⭐ (低)
